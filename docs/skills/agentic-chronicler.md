# Skill: Agentic Chronicler

**Trigger:** `Architecture & Configuration`
**Context:** When the user asks to add a new dependency, change `build.gradle`, or modify the authentication logic.

## Rules
- Automatically remind the user to document any architectural shifts.
- Draft a short entry for `docs/decisions.md` detailing the rationale behind the architectural or configuration change.
- Present this drafted entry in your response for the user to review.
