# Implementation Plans Audit Log

This directory contains the numbered implementation plans generated by AI agents (or human developers) before executing significant tasks. 

## Rules for AI Agents
1. Every new feature or major refactor MUST have an associated plan file here.
2. Naming convention: `[number]-[short-description].md` (e.g., `0002-add-json-output.md`).
3. The file MUST include the exact user prompt that initiated the task to provide context on *why* the implementation was chosen.
